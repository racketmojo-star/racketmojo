Las palas tienen tres formas. Solo recuerda esto: **la forma determina dónde está el punto dulce, y el punto dulce lo determina todo.**

## Redonda: La Tolerante

Punto dulce en el **centro exacto.** La más tolerante.

| | Redonda |
|---|-------|
| Punto dulce | Centro |
| Tolerancia | ★★★★★ |
| Potencia | ★★★ |
| Control | ★★★★★ |
| Ideal para | Principiantes, control, estilos defensivos |

---

## Lágrima: La Polivalente

Punto dulce **ligeramente arriba.** Más potencia sin las exigencias de la diamante.

| | Lágrima |
|---|----------|
| Punto dulce | Sobre el centro |
| Tolerancia | ★★★★ |
| Potencia | ★★★★ |
| Control | ★★★★ |
| Ideal para | Intermedios, estilos polivalentes |

---

## Diamante: La Rematadora

Punto dulce en la **parte superior.** Máxima potencia, exige técnica precisa.

| | Diamante |
|---|---------|
| Punto dulce | Superior |
| Tolerancia | ★★ |
| Potencia | ★★★★★ |
| Control | ★★★ |
| Ideal para | Avanzados, juego agresivo en red |

---

## ¿Qué Forma Elegir?

- **¿Nuevo?** → Redonda. Siempre.
- **¿6+ meses jugando?** → Lágrima.
- **¿Rematando con confianza?** → Diamante. Solo con buena técnica.

La forma es solo una pieza. Peso, núcleo y superficie interactúan. La combinación correcta depende de cómo juegas tú.
